# 料理レパートリーチェック

作れる料理を「主材×調理法」の地図にすると、手薄なところが見えてくる小さなツール。

- 縦に主材（鶏・豚・牛・魚・卵・豆腐・野菜）、横に調理法（焼く・煮る・炒める・揚げる・蒸す・和える・汁物）の 6×6 の地図
- 定番 48 品のチップをタップして「作れる／作ったことない」を切り替えるだけ
- 作れる料理が 1 つもない組み合わせは「手薄」として目立ち、レシピ検索のキーワードまで表示
- 自分の料理の追加・削除も可能

登録なし、アカウントなし。記録は端末の中（localStorage）だけに保存され、サーバーには送られません。記録は JSON ファイルに書き出して、別の端末へ移すこともできます。
